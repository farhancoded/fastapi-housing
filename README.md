# 🏠 FastAPI Housing Management System

## 📌 Project Overview

FastAPI Housing is a backend application designed to manage
housing listings, users, room applications, and roommate requests.
It provides RESTful APIs for both users and administrators.

---

## 🛠️ Technologies Used

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- JWT Authentication
- REST API

---

## ✨ Main Features

- 🔐 User registration and login
- 👤 User management
- 🏠 Housing listing management
- 📝 Room application system
- 👥 Roommate request system
- 👨‍💼 Admin dashboard
- 🔑 JWT-based authentication
- 🗄️ PostgreSQL database
- 📚 Swagger API documentation

---

## 📦 Dependencies

---

## 🚀 Run Locally

Follow the steps below to run this project on your local machine.

1. Clone the repository
2. Go to the project directory
3. Create virtual environment
4. Activate virtual environment
5. Install dependencies
6. Configure environment variables
7. Run the FastAPI server
8. Open http://127.0.0.1:8000
9. Open /docs for Swagger documentation
